## 一、本周 TOP 候选（5 条）

### TOP 1｜湖北大数据集团按「人/月」单价采购智能体工作台，本地两家供应商进入前三

- 事实：2026-10-13 开标并完成评审，10-15 起公示预成交结果（公示至 10-19）。第一名腾讯云计算（北京），企业标准版 128.7 元/人/月、专享版 205.4 元/人/月；第二名武汉万联星河科技 135.9／215.5；第三名武汉众联恒兴科技 130.0／210.0。采购人为湖北省属国企湖北大数据集团旗下数据开发公司，代理机构为湖北数链招标咨询。来源：[湖北大数据阳光招标采购平台](http://www.hbdsjygzc.com/jyxx/004003/20261014/09dfa51e-cdb4-48db-84a7-7fdde23f97e4.html)（2026-10-14 挂网，A）。
- 战略：企业级 Agent 首次在本地形成「可计价、可招标、可异议」的制度化采购形态，且计价单位是席位而非 token；这为后续政务/国企标段立下评分与报价范式。
- 市场：三家报价收敛在 ±6% 内，说明该品类已进入竞争性比价而非独家定制；平台商与本地集成商同台，本地企业以交付角色占两席。
- 人才：直接催生 Agent 部署/交付工程师与场景数据工程岗，要求同时懂国企数据合规与 Agent 编排。
- 机会：公示期内的异议与最终中标公告值得跟踪；创业者可从「工作台之上的行业场景包」（问数、工单、公文、审计）切入，避免与底座正面竞争。边界：报价为投标单价，不等于合同总额，也不证明已交付或已产生付费收入。

## 二、四类雷达与 R3 区域上下游可对接线索

### 战略雷达

- 光谷被上级定位为「光电融合」专精园区：10-15 工信部国家高新区「新赛道·中国行」首次进入中部，明确 15 个重点新赛道方向（含脑机接口、具身智能）、31 家重点园区；光谷提出存算一体产业园、光电融合产业园，预计 2026 年光电子信息产业规模突破 8000 亿元。来源：[21 世纪经济报道](https://www.21jingji.com/article/20261016/herald/768e55eaedc64e0a215d143d2267af74.html)（2026-10-16，A）。
- 政策供给从「给补贴」转向「给资本机制 + 给入口」：容亏率、拨改投、直投允许亏损写进制度；区级算力补贴、市级算力券、OPC 认定三条通道统一收敛到「江城模境」一个平台。
- 出口规则边界收敛：10-16 商务部、科技部第 48 号公告拟将 AI 大模型、智能体、算力集群等 23 项技术列入目录，但明确 API 调用、APP/网页交互、SaaS、端侧轻量化部署不属于出口管理范围；海外本地化部署属管理范围但可适用自动许可。来源：[商务部](https://www.mofcom.gov.cn/syxwfb/art/2026/art_a4acff07e134447fbe7bbeb486df3ea6.html)（2026-10-16，A）。
- 区域竞争位：光谷在「应用交付 + 场景密度」上强，在「运行时/Harness、协议生态、评测与可观测性」上弱；具身智能在「本体 + 零部件」上有供给，在「工站级参数与交付方法论」上弱。

### 市场雷达

- 需求侧出现真实预算而非仅展示：国企智能体工作台按席位计价（约 130 元/人/月标准版）、武汉智博会现场成交 7200 万元与意向 2.6 亿元、中建三局把建筑 AI 智能体列为三大创新产品之一。
- 外部模型侧进入「帕累托改进 + 工具端点变现」：DeepSeek 10-17 发布 V4.1-Flash-1017，同时压低执行时间与输出长度，并把 Search & Fetch 做成 0.75 美元/千次的独立计费端点（10-31 前在指定工具内免费）；Meta 10-15 发布 816B 开放权重模型，把部署下限压到两台桌面工作站，同时设 MaaS 营收超 2000 万美元须另签协议的商业护栏。
- 资本侧：本周本地融资集中在 OCS 光交换、半导体传感、脉冲功率电源；国资增持（华工科技控股股东增持 23.92 万股并披露后续计划）与早期融资在光通信链两端同时加码。

### 人才雷达

- 引才机制从「补个人」转向「补引才主体」：3551 举荐快速通道（领军 200 万元、高层次 100 万元，10-31 截止）与留学回国奖励（A/B/C 类 30/10/2 万元）首次把荐才机构纳入奖励（A 类 10 万元/名），引才奖励按年薪 56 万元门槛给用人单位 5 万元/人。
- 需求结构偏向「应届 + 博士后 + 国资」：长江存储 2027 届校招宣讲密集、博士后综合年薪 40–60 万元（报名 10-10 至 10-16）；光谷金控 2027 届校招 20 人，专业目录写入人工智能、人形机器人、脑科学及脑机接口、高端芯片、时空智能、算力与大数据。
- 紧缺方向：世界模型与三维视觉、推理优化与异构调度、Agent 安全与评测、既懂工艺又能驻厂交付的应用工程师（FDE 型）。

### 机会雷达

- 30 天内可执行：算力补贴（10-20）、算力券核销（10-31）、OPC 认定（常态化）、3551 举荐与留学回国奖励（10-31）。
- 1—2 个季度：以 MIT 许可的开源基座 + 国产算力 + 行业数据做适配打包，切省级政务平台向地市区县复制的需求；关键是发布可复现的适配基准（吞吐、时延、显存、精度损失）。
- 6—12 个月：围绕江城模境做第三方服务（评测、合规、数据标注、算力调度）；围绕具身智能做「工站级集成」而非再招整机厂。

**重点深拆二：DeepSeek V4.1-Flash-1017**

本周动态：10-17，DeepSeek 发布 V4.1-Flash-1017，官方定位为 V4.1-Flash 的小版本更新，但称在 reasoning、coding、agentic tasks 与视觉基准上有实质改进，并同时降低任务执行时间与输出长度。模型卡给出的官方自测对照为：HLE 无工具 42.6（上一版 36.8）、Terminal-Bench 4.0 42.3（31.2）、DeepSWE v1.1 77.0（74.2）、ProgramBench 29.1（20.3）、NL2Repo-Bench 68.2（65.4）、Automation-Bench 60.5（54.8）、Agents' Last Exam 35.4（31.8）、Apex Bench v1.1 72.1（64.6）、Chartography 83.0（78.9）、BabyVision 92.5（89.6）、ZeroBench 51.0（49.0）；同表列出 K3、GLM-5.3、GPT-5.6 Sol、Opus 5 作为对照，其中 Opus 5 在 HLE（56.3）、Terminal-Bench（51.8）、ProgramBench（37.0）、NL2Repo（75.3）仍领先。发布同日，官方宣布 Search & Fetch API 向所有用户开放，由自建搜索引擎支撑，每个端点 0.75 美元/千次调用，经 DeepSeek Harness、Claude Code、Codex 的服务端工具调用在 2026-10-31 16:00 UTC 前免费，之后开始计费；已针对 DeepSeek Harness（需 v0.2.1-rc.1 及以上）、腾讯 CodeBuddy、WorkBuddy 做适配。来源：[Hugging Face 模型卡](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017)（2026-10-17，A）、[官方发布稿](https://api-docs.deepseek.com/news/news261017/)（2026-10-17，A）。

产品与技术栈：MoE 加非对称编码器/解码器、原生多模态、1M token 上下文、建议 max_tokens 不低于 256K、推荐 temperature 1.0 与 top_p 1.0；工程侧本次不提供 Jinja 格式 chat template，改以 encoding 目录下的自包含 Python 参考实现交付，覆盖多轮对话、工具调用、thinking 模式、数值化 reasoning effort、会话中途 system message、交错图像内容；生产环境另发 deepseek-recipe（Rust 库加 Python 绑定），把 Messages、Chat Completions、Responses API 请求转为 Conversation 格式并编解码为 prompt 或 token ID。许可为 MIT（模型权重与仓库）。

客户与商业化：官方披露的使用面是编码与 Agent 工作流——Terminal-Bench 用 Claude Code harness 测、DeepSWE 用 mini-swe-v2 harness 测，说明其优化目标是在别人的 agent 框架里干活；官方演示为端到端项目生成。真实客户名单、行业分布、付费企业数未披露。可核定价只有 Search & Fetch 每端点 0.75 美元/千次调用；模型 API 价格本次未在 1017 页面给出具体数字，仅延续 9-10 的峰谷定价框架。收入、毛利、付费客户数、token 处理量均未披露。

竞争与短板：官方自测表显示其在 HLE、Terminal-Bench、ProgramBench、NL2Repo 上仍落后 Opus 5，属高性价比追赶者而非全面领先；不提供 Jinja chat template、要求调用方自行处理编码与推理，接入门槛高于主流开源模型；Search & Fetch 依赖自建搜索引擎，索引覆盖、时效与合规边界未披露，10-31 后计费会直接抬高 Agent 成本；开源加 MIT 意味着难以靠权重本身变现，商业价值必须落在 API、工具端点与企业服务上。

与光谷的关系：MIT 许可加 1M 上下文加低激活参数，对做私有化部署、行业微调的团队是最低成本的基座选择，尤其适合政务、制造、医疗等不能出域的场景；非对称架构与 KV cache 压缩（1/4 HBM、1/8 SSD）直接降低推理显存与存储门槛，与算力补贴按实付费用补贴形成组合；deepseek-recipe 的 Rust/Python 双绑定为本地推理服务与 Agent 中间件厂商提供标准化接入层。反过来，光谷目前没有与之对位的基座模型主体，这是结构性差距。

**补充对照：Meta Muse Spark Open 816B-A42B**

2026-10-15 发布开放权重，816B 总参数、42B 激活、1M token 上下文、原生多模态、256 专家 top-8 路由、62 层、GQA（128 Q / 16 KV）、1.8B 感知编码器，训练语料含 100 多种语言。官方称可在两台 M5 Ultra Mac Studio（各 512GB 统一内存、1.2TB/s 带宽）上用 MLX 跑起整模型；自托管硬件门槛为 NVFP4 需不低于 700GB 显存、BF16 需 2TB。推理引擎覆盖 SGLang、vLLM、TensorRT-LLM、HF Transformers、MLX、llama.cpp、Unsloth。许可为 Muse Model License（非 OSI 开源）——允许商用、微调、蒸馏、再分发，但要求产品界面显著标注「Built with Muse Spark Open」；若以 Model as a Service 形式对外提供且连续 12 个月合计营收超过 2000 万美元，须先通知 Meta 并另签书面协议。官方自测 Artificial Analysis Intelligence Index 39（Qwen3.8-2.4T 40、GLM 5.3 45、Kimi K3 44）。来源：[Meta 官方博客](https://research.meta.ai/blog/muse-spark-open)（2026-10-15，A）、[模型卡](https://huggingface.co/meta-models/Muse-Spark-Open-816B-A42B)（2026-10-15，A）。

判断：真正信号不是最强，而是把 816B 级模型的部署下限拉到两台桌面工作站——私有化大模型的硬件门槛从机房级降到工作室级。对光谷中小行业模型团队，这是不出域、不租云的新选项；但 2000 万美元 MaaS 条款与品牌标注要求，对想做 API 转售的团队构成实质约束，商用前必须读许可原文。相较 DeepSeek 的 MIT，Meta 的开放权重加商业护栏路线更适合自用与产品内嵌，不适合做模型转售生意。

**重点深拆一：元一智能（ArcheOne AI）**

两条独立官方渠道在本周同时落稿：湖北省经信厅与武汉市科技局（均 10-15）分别发布《成立不到一年，这家光谷企业拿下国际顶级冠军》。本周性需说清：比赛结果与论文是 9 月上旬公布的，本周新增的是省级与市级官方渠道的正式确认与人物叙事，因此按「本周获得权威确认」处理，而不是「本周夺冠」。技术内容上，Track 1 要求系统在多路相机画面中识别并持续跟踪人与货物的三维位置，难点在于仿真训练的模型换到真实仓库后因相机布设变化而失效。GaugeAlign 利用已有相机标定把检测器统一到同一坐标系，再把预测映射回现场坐标，不需要重新训练模型。产业含义比竞赛名次更重要——仓库、产线、门店的相机布点几乎每家都不同，如果每次换场地都要重训，部署成本会吃掉全部毛利；用标定做几何对齐，等于把最后一公里适配从数据工程降级为施工工程。

本体与栈：不做通用本体，主打大脑——ArcheOne-Brain 聚焦长期记忆、世界理解与复杂任务调度规划；感知层强项是多相机 3D 感知与跨场地几何对齐；执行层通过机器人本体适配对接第三方本体；商业模式指向面向机器人厂商提供模型与软件服务。目标场景：近期 1 至 2 年明确列出巡检、特种场景、商超；已验证热干面机器人与巡检机器人；中长期指向家庭、办公强人机共存场景。成熟度：受控或限定场景产品验证，无台数、无客户名、无连续运行时长；竞赛层面是公开基准的 SOTA 级结果，但不证明现场鲁棒性。客户证据、交付数量、价格与 TCO、ROI 全部未披露。

可靠性风险：GaugeAlign 隐含强前提——相机标定必须可得且准确。标定一旦漂移（震动、温度、重新布点），几何换算即失效，且失效方式是静默输出空结果而非报错，这在实际运维中是危险的失败模式，需要额外的标定自检与漂移告警；且不重训只解决坐标规范问题，不解决外观域偏移（光照、包装变化、遮挡）。人在环方面，限定场景验证阶段必然依赖现场人员兜底，接管率未披露。

与光谷的关系：直接竞争加可借鉴。艾利特大本营苏州恰好是光谷最想对标的两条产业链——光模块与消费电子代工；光谷有光迅、华工正源等光模块厂与联想武汉、小米武汉等终端厂，理论上正是其 AI Infra 与 AI Terminal 客户的聚集地，但艾利特把光模块全工艺段量产的首发地放在苏州，并未在光谷设点。这意味着光谷的光模块产线自动化订单很可能流向长三角供应商。来源：[艾利特官网工博会稿](https://www.elibot.com/about/news/ciif-2026-multiform-robot-collaboration)（2026-10-12，B）、[美通社通稿](https://www.prnasia.com/story/551571-1.shtml)（2026-10-13，B）。

**光谷机会与差距**

- 机会一：供应链本地化已过能用门槛，未过敢用门槛。启灵神农核心零部件八成来自湖北本土，可点名到万象奥科（主控）、元生创新（小脑）、极动智能与聚芯微（视觉）、科峰智能（减速器）；加上泛洲谐波、湖北开特、空心杯电机，湖北在减速器、电机、关节模组、视觉、主控五个层级都有本地供给。差距不在有没有，而在敢不敢批量用——整机厂在关键工序上仍倾向用已验证的进口或长三角部件，本地部件缺少长周期工况数据与失效样本库。
- 机会二：场景与第一个客户已就位。湖北科投把光谷数智经济产业园当第一试验场，无人清扫车、安防巡检机器人、幕墙清洗无人机已在园区常态运行；启元智域以集中采购、设备租赁、数据平台运营把二三十万元一台的巡检机器狗转成租赁。这是真正的制度优势——有一个愿意承担试错成本的国资买方。差距在规模，目前是园区级、小区级验证，尚未出现整厂级、跨园区级连续运行数据。
- 机会三：高校成果转化密度高，已出现院士团队加产业人的复合结构。元一（华科）、慧力科（华科尹周平院士团队）、启灵（华科丁汉院士团队）、思波微（华科廖广兰团队加深圳产业人）四个样本的共同点是技术来自华科实验室、商业化由懂产业的人操盘。
- 差距一：缺工站级参数的表达能力。艾利特给出的是精度、节拍、行程、温域、防护等级；光谷企业本周的公开表达是自由度、负载、IP67、分级框架——指标是有的，但缺在什么工况下、连续多少小时、良率多少、人工接管率多少这一层。工业客户采购时不看自由度，看节拍、良率、MTBF、换型工时。
- 差距二：缺具名客户加付费交付的证据链。光谷三家企业的客户证据均停留在限定场景验证、门店落地、进入门诊，没有一家公开披露付费客户名、台数、单价。试点不等于付费交付，采购不等于收入。
- 差距三：缺跨场景可复用的部署方法论。元一的 GaugeAlign 只解决看得见的问题，不解决抓得准、放得稳；艾利特的答案是一脑多形加统一控制器加工站级参数库；光谷目前是一企一策，每家整机厂自己攒供应商、自己做适配。慧力科的 L0 至 L5 分级是朝评估标准走的一步，但只覆盖交互，不覆盖操作。
