## 快速定位：每份 Prompt 里增强章节在哪

七份主题 Prompt 的增强内容统一位于文件顶部的前置区块，标题为：

```
## 🧩 读者定位与增强透镜（<主责需求>）
```

打开任意一份，搜索 `🧩` 即可跳到增强章节。该章节均以引用 `_reader-positioning.md` 开头，并写明「**增强只换视角，不扩检索；当前超时预算未变**」。

## 三条硬约束（写在各份 Prompt 里）

1. **只重构视角，不扩大检索**：不新增必查对象、行业或并行研究组。当前 7 个任务的超时预算未变，不得因透镜增加单期工作量。
2. **不降低证据标准**：新透镜下每句判断仍走原证据分级；未披露就写「未披露」，宁可空缺不推测。
3. **不新增执行机制**：不新增任务、执行器、自动恢复服务；不改日程、模型、超时、并发、权限与发布流程。
